📊 โมดูลหน้าหลักและแดชบอร์ด (11 เคส)
1.attendance.sheet — หน้าเช็กชื่อรายวัน (กรองเฉพาะนักเรียนในห้องที่เลือก โหลดไวขึ้น)

2.attendance.history — หน้าประวัติการเช็กชื่อย้อนหลัง (จำกัดช่วงวันที่และดึงเฉพาะห้อง)

3.assign.list — หน้างานที่มอบหมายและการบ้าน (คัดกรองข้อมูลและสรุปสถานะการส่ง)

4.visit.list — หน้าบันทึกเยี่ยมบ้าน (เลือกดึงเฉพาะคอลัมน์ที่จำเป็น พร้อม Memory Cache)

5.student.list — หน้าทำเนียบรายชื่อนักเรียน (คงระบบค้นหาปลอดภัย, จัดเรียงลำดับชั้น, และดึงข้อมูลห้องคู่ขนาน)

6.home.dashboard — หน้าแดชบอร์ดหลัก (ใช้ Promise.all ดึงทุกตารางพร้อมกัน + Memory Cache 1 นาที)

7.exec.dashboard — หน้าแดชบอร์ดผู้บริหาร (ดึงสถิติภาพรวมโรงเรียนแบบคู่ขนาน)

8.case.list — หน้าคัดกรองช่วยเหลือนักเรียน (ใช้ Promise.all และ Memory Cache)

9.doc.list — หน้าเอกสารโรงเรียน (ดึงเอกสารและห้องเรียนแบบคู่ขนาน พร้อมแคช)

10.daily.list — หน้าบันทึกประจำวันครู (ดึง Logs, Users, Classrooms แบบคู่ขนาน)

11.behavior.list (พูดคุยและจัดระเบียบโครงสร้างภาพรวมพฤติกรรม)

⚙️ โมดูลระบบและยูทิลิตี้เบื้องหลัง (4 เคส)
1.notify.tasks — ระบบแจ้งเตือนงานและภารกิจ (ดึงข้อมูล Assignments, Cases, Events พร้อมกันด้วย Promise.all)

2.audit.list — ระบบตรวจสอบประวัติการใช้งาน (จำกัด 200 รายการล่าสุด และเลือกเฉพาะคอลัมน์จำเป็น ป้องกันแรมบวม)

3.system.status — ตรวจสอบสถานะระบบและนับจำนวนข้อมูล (ใช้ Promise.all นับตารางหลักพร้อมกัน)

4.system.cache — ระบบเคลียร์แคช (อัปเกรดให้ล้างตัวแปร Memory Cache ทุกตัวในเซิร์ฟเวอร์แบบสะอาดหมดจด)
